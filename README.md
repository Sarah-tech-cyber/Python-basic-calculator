# Python-basic-calculator
Python Calculator

A simple Python calculator that performs basic arithmetic operations on two numbers entered by the user.

Features

* Performs basic arithmetic calculations.
* Accepts two numbers from the user.
* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Modulo (%)
* Checks for division by zero.

How to Run

Run calculator.py using Python.

Project Purpose

This project was created to practise Python programming, conditional statements, user input, and basic arithmetic operations.

How to Run

1. Make sure Python is installed.
2. Run the calculator.py file.
